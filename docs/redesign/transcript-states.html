Transcript states

The primary screen shows the healthy path. These are the states that actually stress the ordering: a step that fails, a recovery that has to prove it changed something, a run that stops and needs the user, and an honest final grade. Each is rendered at the transcript's real column width, on the real ground, using the same tokens.

03

Recovery — strategy changed

Recovery is only meaningful if the next attempt is materially different, so the change itself is the content: what was tried, what is being tried instead, and why. A strategy already attempted for this failure category is never re-dispatched — when nothing different remains, the run stops instead of looping.
